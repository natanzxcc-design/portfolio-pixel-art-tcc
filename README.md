# Portfólio de Pixel Art — TCC

Portfólio de artes em pixel art desenvolvidas para um projeto acadêmico de jogo digital. Aqui estão reunidos cenários, personagens, animações, inimigos, ícones e elementos de interface produzidos para o jogo.

## Sobre o projeto

Este repositório apresenta uma seleção das minhas contribuições artísticas para **Reminiscence of Shatters**, um jogo desenvolvido em equipe como parte do Trabalho de Conclusão de Curso (TCC).

O objetivo deste portfólio é apresentar meu trabalho com pixel art, destacando os elementos visuais que produzi para compor os ambientes, os personagens e a interface do jogo.

**Repositório do jogo original:** [Reminiscence of Shatters](https://github.com/kauanperesrs/Reminiscense-of-shatters)
