Portfólio de Pixel Art — TCC
Sobre o projeto
Este repositório reúne uma seleção de trabalhos de pixel art desenvolvidos para Reminiscence of Shatters, um jogo acadêmico produzido como parte do Trabalho de Conclusão de Curso (TCC).
O objetivo deste portfólio é apresentar minhas contribuições artísticas para o projeto, incluindo cenários, personagens, inimigos, animações e elementos de interface.
Minhas contribuições
As artes estão organizadas nas seguintes categorias:
•	Cenários e ambientes
•	Personagens e animações
•	Inimigos
•	Ícones e elementos de interface
